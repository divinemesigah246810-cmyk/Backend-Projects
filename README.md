# Backend Projects

This repository contains backend projects developed using C++ and Python
to practice programming, problem-solving, data management, calculations,
and the development of basic real-world management systems.

## Projects

### C++ Projects

- **Student Report Backend** — A system for managing student academic
  records, calculating GPAs, and generating transcripts.
- **Delivery System** — A system for calculating delivery charges and
  determining total delivery costs.

### Python Projects

- **Bank System Backend** — A basic bank management system.
- **Hospital System Backend** — A basic hospital management system.

## Technologies Used

- C++
- Python

## Purpose

These projects were developed as part of my programming practice and
demonstrate my experience applying programming concepts to practical
system-development problems.
