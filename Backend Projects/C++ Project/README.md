# C++ Projects

This repository contains C++ projects developed to practice programming,
problem-solving, data management, and system development.

## Projects

### 1. Delivery System

The Delivery System is a C++ project designed to calculate delivery
charges and determine the total cost of a delivery.

#### Features

- Calculate delivery charges
- Calculate total delivery cost
- Process delivery-related information
- Interactive system for delivery calculations

#### What I Learned

Through this project, I practiced implementing calculations and developing
program logic in C++.

### 2. Student Report Backend

The Student Report Backend is a C++ system designed to manage student
academic information, calculate GPAs, and generate student transcripts.

#### Features

- Student record management
- Subject and grade management
- GPA calculation
- Transcript generation
- Academic data storage
- Interactive menu system

#### What I Learned

Through this project, I practiced working with student records, processing
academic data, calculating GPAs, storing information, and generating
structured reports using C++.
